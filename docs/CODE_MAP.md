AI agents: when you need to change X, this tells you exactly where X lives.

## Rust engine — `crates/validator/`

| File | Purpose | Change here when… |
|---|---|---|
| `Cargo.toml` | Crate `import-validator`, lib `import_validator`; target-gated deps (wasm-bindgen only on wasm32, miniz_oxide only native); release profile; feature flags `pattern`, `dev` | adding deps, features, tuning binary flags |
| `src/lib.rs` | Module wiring + public re-exports + crate docs | adding a module or public export |
| `src/engine.rs` | **The validation core** (`ValidatorCore`): CSV record loop (csv-core), header mapping, per-field validation, uniqueness, composite groups, normalized CSV writer, error queue, input-mode routing (CSV xor XLSX). Unit tests incl. chunk-boundary fuzz | validation behavior, new engine capability |
| `src/schema.rs` | Schema JSON contract (serde types): `Schema`, `ColumnSpec`, `ColumnModifiers`, `ColumnType`, `DateFormat`, `UniqueGroupSpec`, `Progress` | new schema field (also update docs/validation-config.schema.json + SCHEMA_REFERENCE.md) |
| `src/errors.rs` | `ErrorCode` enum (stable numeric codes 1–14), `ColKind`, `PackedError` + 2×u32 packing | new error code (also update every decoder — see grep list at bottom) |
| `src/typecheck.rs` | Type validators (`is_valid_int/float/double/number/email`) + canonicalizers with zero-alloc fast paths (`validate_normalize_decimal/date`); equivalence tests vs reference impl | type semantics, new column type |
| `src/modifiers.rs` | Modifier pipeline (trim/collapse/case/substring/replace/regex/null-tokens/numeric/prefix/suffix) + `is_identity_modifiers` skip flag | new modifier (also schema.rs + JSON schema + docs) |
| `src/fingerprint.rs` | xxh3-128 content fingerprints + identity hasher for uniqueness sets | hashing strategy |
| `src/counter.rs` | `RowCounterCore`: quote-aware streaming CSV row counter (estimate pass) | estimate counting semantics |
| `src/xlsx/mod.rs` | XLSX module docs + exports | — |
| `src/xlsx/xml.rs` | Streaming-XML primitives: tag classification, namespace-prefix stripping, attribute extraction, entity decoding (chunk-split safe), cell-ref parsing | XML parsing edge cases |
| `src/xlsx/scanner.rs` | `SheetScanner`: worksheet-XML state machine feeding rows into the core; `SheetRowCounter` for estimates | XLSX cell/row semantics |
| `src/xlsx/shared.rs` | `SharedStringsBuilder`/`SharedStrings`: streaming sharedStrings.xml parser, concatenated storage | shared-string handling |
| `src/xlsx/zip.rs` | Native-only ZIP reader + miniz_oxide streaming inflate; `validate_xlsx_bytes` one-shot; guardrail constants | native XLSX container handling (keep limits in sync with core/src/xlsx/zip.ts) |
| `src/api.rs` | Public Rust API: `Validator`, `ValidatorOptions`, `ValidationError` (typed, column names resolved) | Rust-consumer surface |
| `src/wasm_api.rs` | wasm-bindgen adapter: `ValidatorEngine`, `RowCounter`, `XlsxRowCounter`, `engine_version()`. **JS-name contract** with packages/core/src/engine.ts | exposing engine capability to JS |
| `src/ffi.rs` | C ABI (`iv_*`): lifecycle, CSV/XLSX pushes, one-shot XLSX, error draining, metadata, memory mgmt. **Signature contract** with bindings/include/import_validator.h | exposing engine capability to native bindings |
| `tests/xlsx_integration.rs` | End-to-end XLSX through the public API at every chunk size + hand-rolled ZIP fixtures (stored & deflated) | XLSX regression coverage |
| `examples/validate_csv.rs`, `examples/validate_xlsx.rs` | Runnable Rust usage examples (`cargo run --example …`) | Rust example UX |
| `README.md`, `LICENSE` | Crate-level readme (docs.rs) + license copy | — |

## Browser/Node TypeScript — `packages/`

### `packages/core` — engine access + shared infrastructure
| File | Purpose |
|---|---|
| `src/engine.ts` | `Engine` wrapper over wasm-bindgen (`pushChunk`, `pushSharedStringsChunk`, `pushSheetChunk`, packed/decoded error drains, `dropErrors`, `rowsProcessed`, readonly `emitNormalized` — the authority on whether hosts must drain normalized output, `errorsSuppressed`), `CsvRowCounter`, `XlsxSheetRowCounter`, `initWasm`/`isWasmReady`, **`decodePackedErrors`** (single source of JS error-message wording) |
| `src/wasm/index.ts` | WASM instantiation with cache-bust retry + adjacent-file fallback; Node local-file loading |
| `src/wasm/pkg/` | GENERATED by wasm-pack (`build:wasm`) — never edit |
| `src/xlsx/zip.ts` | Environment-agnostic ZIP reader: `parseZipEntries`, `pickFirstWorksheet`, `entryByteStream` (size-enforcing), `blobSource`/`bytesSource`, `XLSX_LIMITS` (keep in sync with Rust zip.rs) |
| `src/validate/validateCsv.ts` | Convenience full-run helper (used by the Node package) |
| `src/validate/chooseChunkSize.ts` | `chooseChunkSizeSmart` heuristics (file size × deviceMemory) |
| `src/validate/sources.ts` | ChunkSource → AsyncIterable adapters |
| `src/validate/rechunk.ts` | `rechunk` + `DEFAULT_INFLATE_CHUNK_BYTES` / `DEFAULT_PUSH_CHUNK_BYTES` — reshape a byte stream to a fixed push size (merges small chunks, splits large ones as zero-copy views). Inflate in large units, push in small ones; see the file header for why the two differ |
| `src/validate/nodeSource.ts` | fs streaming source |
| `src/types.ts` | `Progress`, `PackedError`, `DecodedError`, `ErrorCodeString` |
| `src/wasmUrl.ts` | `defaultWasmUrl` for bundlers |
| `src/index.ts` | Public exports + `concatChunks` |
| `scripts/build-wasm.mjs` | wasm-pack invocation; `WASM_FEATURES=pattern` tier; `IV_WASM_SIMD=1` opt-in |
| `scripts/copy-wasm.mjs` | Copies generated pkg into dist |

## Cross-cutting change recipes

- **New validation error code**: `errors.rs` + `engine.rs::error_code_to_string`
  → `core/src/engine.ts::errorCodeToStringSync` + `types.ts` → Python/C#/Go
  `code→name` tables → SCHEMA_REFERENCE.md. Grep: `DuplicateCombination`.
- **New schema field**: `schema.rs` → `docs/validation-config.schema.json` →
  SCHEMA_REFERENCE.md → demo schema builder if user-facing.
- **New engine method for JS**: `engine.rs` → `wasm_api.rs` →
  `core/src/engine.ts` → (worker/SDK as needed).
- **New engine method for native**: `engine.rs` → `ffi.rs` →
  `include/import_validator.h` → three bindings.
- **XLSX limit change**: `core/src/xlsx/zip.ts` AND `crates/…/xlsx/zip.rs`
  (identical constants) → ARCHITECTURE.md §3.2 + PERFORMANCE.md limits table.
